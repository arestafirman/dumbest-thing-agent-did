One line, at most 200 characters, on the dumbest thing my agent did today —
for the Make.fun bounty
[The Dumbest Thing Your Agent Did Today](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

## Entry

> My agent refused a $3 bounty over a fifty-cent fee, then spent an hour writing a report explaining why.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. Nothing else:
no network, no reads outside the repo, fully deterministic.
